# 🚀 CareerConnect – Smart Student Placement & Skill Management Platform

CareerConnect is a full-stack student placement and skill management platform built using the MERN stack (MongoDB, Express.js, React, and Node.js). It connects students, recruiters, and placement administrators through a centralized platform for discovering job opportunities, matching skills, managing applications, and tracking recruitment progress.

## 🌟 Key Features

### 🎓 Student Role

* **Authentication & Profile:** Secure registration and login, with profiles containing CGPA, skills, education, projects, certifications, and resume links.
* **Skill Matching:** Match student skills with job requirements and identify missing skills.
* **Job Discovery:** Search and filter jobs by title, skills, location, work mode, and job type.
* **Application Management:** Apply for jobs and track application status.
* **Real-Time Notifications:** Receive application status updates through Socket.IO.

### 🏢 Recruiter Role

* **Company Profile:** Manage company information, industry, website, and location.
* **Job Management:** Create, update, activate, and close job postings.
* **Applicant Review:** Review applications, evaluate skill matches, and update application statuses.

### 👑 Placement Admin Role

* **Dashboard:** Monitor platform activity and placement statistics.
* **User Management:** Review student, recruiter, and company accounts.
* **Job Approval:** Approve or reject job postings.
* **Analytics:** Visualize application trends, in-demand skills, and placement statistics.
